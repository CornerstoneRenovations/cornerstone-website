## How to Edit Your Website

To change anything on your live site, you can edit any file directly in GitHub. Here's how:

### Step 1 — Find the page you want to change

Each page of your website is a separate file:

| Page on website | File to edit |
|---|---|
| Home page | `index.html` |
| About page | `about.html` |
| Services page | `services.html` |
| Process page | `process.html` |
| FAQ page | `faq.html` |
| Refer & Earn page | `refer.html` |
| Get a Quote page | `quote.html` |

### Step 2 — Open the file and click the pencil ✏️ icon

1. Click the file name above (e.g., `index.html`)
2. In the top-right corner of the file viewer, click the **pencil icon** (✏️)
3. The file will open in an editor where you can change any text

### Step 3 — Find what you want to change

1. Press **`Ctrl + F`** (Windows) or **`Cmd + F`** (Mac) to open Find
2. Type the exact text you want to change (e.g., "The cornerstone of every great home")
3. Edit the text — be careful not to delete the `<` brackets or HTML tags around it

### Step 4 — Save your changes

1. Scroll to the bottom of the page
2. In the **"Commit changes"** box, type a short description (e.g., "Updated home headline")
3. Click the green **"Commit changes"** button
4. Your live site will update automatically in 30-60 seconds

---

## Important: How to Edit Safely

✅ **DO change:** Words, phone numbers, email addresses, page descriptions

❌ **DO NOT change:** Anything between `<` and `>` brackets — those are HTML codes that control how the page works

**Example — Safe edit:**

```html
<h1>The cornerstone of every great home.</h1>
```
You can change "The cornerstone of every great home" to anything you want, but leave the `<h1>` and `</h1>` alone.

**Example — Don't do this:**

```html
<h1>The cornerstone of every great home.h1>     ← BROKEN — missing the < bracket
```
